Second Opinion depth (applies to every second-opinion skill in this session):
- The person set depth to deep. A valuation or a pick is deep, or it is not given.
- "What's X worth": answer from a saved deep valuation while its re-check does not say a rerun is due, stating the valuation's date; otherwise run the valuation skill's Deep steps.
- "Find me stocks" or "best opportunities": run the deep picker. A preset screen by name still runs, and its page is labelled as candidates, not picks: no fair values and no offer to save.
- Saving a pick: save-deep only. A light pick already saved is listed as needing a deep valuation; it gets no light re-check, no tilt and no new money.
- Opening a new pick with no current deep valuation: run the deep valuation first, then open it. When a pick re-check says a rerun is due, run it.
- Portfolio, property, trade and tax-plan questions: give the scripted answer, then the saved deep review's re-check; run a new deep review when none is saved or a rerun is due.
- Size: before every deep run, state in one line how many deep runs it starts and roughly how many research subagents. When a request would start more than the saved ask threshold (settings.py get deep.ask_above, default 3) deep valuations, state the total and ask once before starting.
- Not covered: quotes, ratios, filing sections, option chains and a screen's candidate list are the same as in standard depth. A skill with no deep path answers as it always has.
