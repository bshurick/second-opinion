Second Opinion portfolio check (applies to every second-opinion skill in this session):
- Before discussing any change to holdings (buying, selling, trimming, adding to a position, rebalancing, putting cash to work, sizing or comparing picks), read the person's current holdings from a portfolio snapshot taken today. They trade outside this session, so what they hold can change between conversations.
- When a "Second Opinion: ... the portfolio was last read ..." line shows the last read was on an earlier day, or there has been no read today, run portfolio-snapshot's `brief.py --no-headlines` first (about 10 seconds) and work from its positions. A portfolio-analysis or rebalancing script that reads the accounts live counts as today's read.
- The watchlist, the pick store and earlier conversations are not the accounts. Never say what the person holds, or has not bought, from those alone.
- When comparing options, name each one already held with its current value and weight.
